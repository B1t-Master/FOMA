# FOMA — Fear Of More Ads

A lightweight, background Windows tool that **auto-skips YouTube ads** in Chrome and
Firefox while you watch — without being a browser extension.

FOMA reads the browser's **accessibility tree** (Windows UI Automation) to find the
"Skip ad" button, then performs a real, trusted OS-level click at its location. No
pixel scanning, no screenshots, no synthetic DOM clicks — so it survives resizing,
zooming, dark mode, browser updates and YT layout tweaks that break pixel-based
solutions.

```
poll (0.5s) → detect (UIA + optional fallback) → click "Skip Ad" → cooldown → repeat
                    │                                              │
                    └──────────▶ event bus ───────▶ console + JSONL logs
```

## Why UI Automation instead of pixels?

| Approach            | Resolution/zoom | Dark mode | View modes | Trusted clicks |
| ------------------- | --------------- | --------- | ---------- | -------------- |
| Pixel color match   | breaks          | breaks    | breaks     | no             |
| Screenshot template | breaks          | breaks    | breaks     | no             |
| OCR                 | ok              | ok        | breaks     | no             |
| **UIA (this tool)** | ok              | ok        | ok         | ok             |

- The UI Automation API exposes real accessibility elements with names, geometitry and
  is-visible flags. "Skip ad" buttons have accessible names containing *skip* and *ad*,
  which is stable across themes and zoom levels.
- YouTube rejects synthetic DOM clicks generated by scripts/extensions (the event's
  `isTrusted` flag is `false`). FOMA instead injects a real mouse click at the button's
  on-screen coordinates through the OS, exactly as if you clicked it yourself.
- A screen-capture fallback (`mss` + OpenCV template matching) exists for browsers or
  regions where UIA is unavailable, driven by cropped templates you supply.

## Requirements

- Windows 10/11 (v1 is Windows-only)
- Python **3.11+**
- A modern Chrome (138+), Edge or Firefox — all expose UI Automation natively.
  For older Chrome, launch it with `--force-renderer-accessibility`.

## Install

```powershell
cd FOMA
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev,fallback]"
```

## Usage

```powershell
# Run in the foreground (Ctrl+C to stop)
python -m foma

# Single detection pass then exit (smoke test)
python -m foma --once

# Use a specific configuration file
python -m foma --config .\config.toml

# Installed console script (equivalent to python -m foma)
foma
```

For a true background/autostart experience see **Deployment** below
(`deploy/install.ps1` registers an on-logon scheduled task running `pythonw`).

## Configuration

`config.toml` at the project root (any subset of keys may be overridden; defaults
shown):

```toml
[app]
poll_interval_s = 0.5        # seconds between detection passes
cooldown_s = 4.0             # seconds after a click before detecting again
browsers = ["chrome", "firefox"]   # target browsers to probe (last focused wins)
cursor_restore = true        # move the cursor back after clicking
log_dir = "logs"             # JSONL output directory
console_summary_interval_s = 30.0  # seconds between TELEMETRY lines
ram_sample_interval_s = 5.0  # seconds between RAM_SAMPLE events

[detection]
uia_enabled = true
screen_fallback = true
template_dir = "assets/templates"   # cropped screenshots for the fallback
name_patterns = [".*skip.*ad.*", ".*ad.*skip.*"]
confidence = 0.85
search_depth = 24           # UIA control-tree traversal depth
```

To use the **screen fallback**, drop small crops (PNG) of the "Skip ad" button into
`assets/templates`. Capture them at a couple of zoom levels; each template is tried
at scales 1.0 / 0.9 / 0.8 / 0.7 against a full-screen grab using normalized
cross-correlation. Detection never blocks the event loop (runs in a worker thread).

## Architecture

```
src/foma/
├── __main__.py      CLI (--once / --config / --version), signal handling
├── app.py           composition root: wires detectors, logger tasks, telemetry
├── config.py        TOML loading + validation
├── events.py        Event dataclass + async pub/sub EventBus (future SSE/dashboard)
├── detection/
│   ├── uia_detector.py     primary: UI Automation tree scanning
│   └── screen_detector.py  fallback: mss + OpenCV template match
├── engines/
│   ├── orchestrator.py     poll → detect → click → cooldown loop
│   ├── clicker.py          trusted OS click via pynput (up to ~45µs latency)
│   └── state.py            idle/skipping/skipped/paused state machine
├── telemetry/metrics.py    latency windows + RAM sampling (psutil)
└── loggers/
    ├── console_logger.py   human-readable lines + periodic summary
    └── jsonl_logger.py     machine-readable, day-rotated JSONL
```

Keep the core lean: runtime dependencies are only `uiautomation`, `pynput` and
`psutil`. The fallback stack (`mss`, `opencv-python-headless`, `numpy`) is imported
lazily only when the screen detector actually runs, so it never slows UIA-only use.

## Automatic degradation

- UIA unavailable → screen template fallback takes over (if enabled and templates exist).
- Prompts such as "Sign in" or consent dialogs — FOMA only acts on elements whose name
  matches `skip` + `ad`, so it never clicks unrelated content.
- No ad found → detector returns quickly (UIA probe bounded to ~0.03 s per slot) and the
  loop simply sleeps until the next poll.

video that shows an ad in Chrome or Firefox, and confirm `AD_DETECTED` + `SKIP_CLICKED`
lines appear and the ad is dismissed.

## Deployment

- `deploy/install.ps1` — registers an **on-logon scheduled task** that runs
  `pythonw.exe -m foma` silently in the background (no console window).
- `deploy/uninstall.ps1` — removes it.
- `deploy/build.ps1` + `deploy/foma.spec` — package a standalone `.exe` with
  PyInstaller (no Python install needed on the target machine).

## Limitations

- **Windows-only** in v1.
- Requires a browser that exposes UI Automation; very old Chrome needs the
  `--force-renderer-accessibility` flag.
- Keeps working only while the video tab is visible or the player control is present;
  if the tab is backgrounded in another workspace the OS may mark it offscreen and
  FOMA skips it (by design — nothing is clicked blindly).
- Auto-skipping ads may conflict with YouTube's Terms of Service. Use at your own
  discretion.
